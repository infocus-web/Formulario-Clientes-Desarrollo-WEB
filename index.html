Cuestionario inicial

Diseñemos la nueva web de la empresa

La idea es desarrollar un sitio web desde cero para presentar sus servicios y facilitar el contacto. Estas preguntas ayudan a definir el alcance y cotizarlo correctamente.

1. Datos de contacto

Los datos se usarán para responder esta consulta.

2. ¿Qué servicios quieren mostrar? *

Pueden elegir varias opciones.

3. ¿En qué zonas trabajan? *

Pueden indicar barrios, localidades o partidos.

4. ¿A qué tipo de clientes atienden? *

Pueden elegir más de uno.

5. ¿Qué secciones les gustaría incluir? *

Pueden elegir varias. Si no están seguros, marquen “Necesitamos recomendación”.

6. ¿Qué formato prefieren para el sitio? *

7. Como opción adicional, ¿les serviría una plataforma de gestión?

La web institucional es el proyecto principal. Esta pregunta es para saber si también quieren cotizar un sistema privado para organizar clientes y trabajos.

8. ¿Qué materiales tienen disponibles? *

Pueden elegir varias.

9. ¿Qué esperan de Google? *

La preparación básica para Google, el trabajo de posicionamiento y los anuncios pagos son servicios diferentes. Se pueden cotizar por separado.

10. Dominio para la nueva web

El dominio es la dirección de la página, por ejemplo: nombreempresa.com.ar.

11. Plazo y presupuesto

Al enviar, las respuestas se guardarán para preparar el presupuesto solicitado.
